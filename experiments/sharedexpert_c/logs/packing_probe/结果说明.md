# verl FSDP2 / Qwen3.5 多序列 packing 实测

记录时间：2026-10-20 00:36（Asia/Shanghai）。完整运行已完成，四个探针 rank 和 torchrun 均退出，GPU 3–6 已释放。未修改生产训练代码、配置、权重或冻结评测集。

## 结论

**当前安装版本的原生 `remove_padding=True` + B2 packing 不能直接视为独立样本的等价计算。** 固定后一个样本全部 token、图片、位置、掩码，仅改变前一个样本的非 EOS 响应 token 顺序，就使后一个样本的 response log-prob 最大改变 0.902136（AB）或 0.751673（BA）。同输入重复和 padded B2 的该因果控制均为 0。这是实际完整多模态模型中观测到的跨样本依赖，不是仅从源码推断。

进程内按文本位置重置点分段执行 linear-attention decoder 后，本次测试中双向因果影响和交换顺序差均为 0，但梯度仍与独立样本计算显著不同，不能宣布训练等价或直接用于正式 300 step。FSDP2 可以运行 B2 前向/反向；这不等于当前 Qwen3.5 混合注意力的原生跨样本拼接在语义上正确。

## 环境与真实调用路径

- 四张 L20，GPU 3–6，真实生产训练 venv、同一 Qwen3.5-4B 初始权重；所有 rank 使用相同两条输入以控制 FSDP 比较，吞吐不把 rank 重复算作不同样本。
- FSDP2、FP32 master weights、BF16 前向、FP32 梯度归约、FlashAttention2、non-reentrant gradient checkpointing；CPU param/optimizer/offload_policy 均关闭；CPU 线程数固定 1。
- 实际调用 `DataParallelPPOActor._forward_micro_batch`，加载实际 verl Qwen3.5 monkey patch，没有自造简化 attention。
- 24 个 GatedDeltaNet 层：`causal_conv1d_fn=None`，卷积走 torch 实现；delta kernel 实际为 `fla.ops.gated_delta_rule.chunk.chunk_gated_delta_rule`。初始化的 aggregate fast-path warning 不能解读为整个 linear attention 都走 torch。
- 当前 HF GatedDeltaNet forward 未接收 `cu_seqlens`；卷积未传序列边界，delta 递归也未传分段边界。完整模型测量与该源码机制一致。
- 参数总量和实际参与梯度元素约 45.39 亿；比较 local FSDP shard 后全局 SUM 平方/内积，不重复归约完整参数。

## 两条真实输入与目标

原始 smoke parquet 的 VQAv2、DocVQA 样本通过真实 `RLHFDataset._build_messages`、`SharedExpertSingleTurn` 与 `AgentLoopWorker` 多模态/mRoPE 方法处理。四轴位置来自真实图片网格。保存过的真实 smoke response 文本重新 tokenize 并统一追加 EOS；VQA 响应 187 token 与原计数一致，DocVQA 重建 250 token、原保存计数 249。本实验对各模式使用同一组重建 token，不宣称逐 token 还原原 rollout。

| 项目 | VQA | DocVQA |
|---|---:|---:|
| Prompt token | 293 | 781 |
| Response token，含 EOS | 187 | 250 |
| 总有效 token | 480 | 1031 |

共同左补齐 prompt 宽 781、右补齐 response 宽 250；有效输入 1511 token，padded 输入 2062 token，计分 response 437 token。响应起点与 actor 默认索引一致，只计真实响应 mask，不计 padding 和拼接序列边界产生的伪标签。BA 模式按原始样本编号还原输出。

测试损失统一为两个样本所有有效响应 token 的 NLL 总和除以 437。独立两次 backward 使用相同总分母，与 B2 同目标。这是诊断 forward/backward 等价的固定 NLL，不是完整 PPO/GRPO 更新；未创建 optimizer，未更新权重。生产配置的 sequence-mean-token-mean PPO 聚合方式未改动。

## 前向结果

每个模式单独 warmup 后重复 3 次计时；下表为跨 rank 最大耗时的中位数。计时含真实 actor 路径和小规模 log-prob CPU 拷贝。所有模式同输入重复的前向差均为 0。

| 模式 | 前向秒/两条 | 对独立最大 log-prob 差 | 对独立 RMS 差 |
|---|---:|---:|---:|
| 独立 B1 + B1 | 1.0671 | 0 | 0 |
| 原生 packed AB | 0.5577 | 1.75448 | 0.16343 |
| 原生 packed BA | 0.5622 | 1.71231 | 0.22262 |
| padded AB | 0.5791 | 0.14834 | 0.02061 |
| padded BA | 0.5778 | 0.14834 | 0.02061 |
| 分段 linear packed AB | 0.6867 | 0.14829 | 0.02236 |
| 分段 linear packed BA | 0.6630 | 0.14829 | 0.02236 |

| 强因果控制 | 原生 packed | padded | 分段 linear packed |
|---|---:|---:|---:|
| 改 A、固定后条 B：B 最大差 | 0.902136 | 0 | 0 |
| 改 B、固定后条 A：A 最大差 | 0.751673 | 0 | 0 |
| AB/BA 交换顺序后最大差 | 1.816448 | 0 | 0 |

padded 和分段模式仍与独立 B1 存在批形状相关差异。BF16 计算、视觉批处理形状或底层 kernel 的影响是待进一步分离的候选原因，本次实验没有证明残差的全部来源；不能用任意宽容差宣布通过。

## 梯度、速度与显存

每个布局做完整真实 backward、单独 warmup、重复同输入 backward，并比较全模型梯度。梯度对照为第一轮独立计算；同模式重复噪声单独列出。下表计时均为 forward + backward，不含全量梯度比较时间。

| 模式 | 相对独立梯度 L2 差 | 梯度 cosine | 同模式重复 L2 差 | 前向+反向秒 | 峰值 allocated GiB |
|---|---:|---:|---:|---:|---:|
| 独立 B1 + B1 | 0（参考） | 1 | 0.01312 | 4.0109 | 17.7095 |
| 原生 packed AB | 1.26150 | 0.45529 | 0.00957 | 2.0739 | 17.0893 |
| 原生 packed BA | 0.66970 | 0.76668 | 0.00901 | 2.1281 | 17.0893 |
| padded AB | 0.80424 | 0.65557 | 0.01960 | 2.3480 | 17.0887 |
| padded BA | 0.81030 | 0.65066 | 0.02551 | 2.1439 | 17.0890 |
| 分段 linear packed AB | 0.38039 | 0.94779 | 0.01558 | 2.2270 | 17.0894 |
| 分段 linear packed BA | 0.37685 | 0.94854 | 0.01812 | 2.2750 | 17.0890 |

独立行的时间/显存取 **independent repeat**，其余取每模式第一次正式测量：这些均保留一份同样的参考 GPU 梯度 shard clone，避免把参考 clone 开销误判为 batching 增加的内存。独立第一次没有 clone、各 B2 第二次有两份 clone，因此不混用于此表。完整两次明细与 peak reserved 在 `report.json` 中。

所有梯度均 finite，无缺失梯度。原生 packed 的大偏差与前向跨样本依赖相互支持；padded 和分段的梯度偏差也明显超过其自身重复噪声，本次未建立它们与独立计算的梯度等价性。短样本约 1.5–1.9 倍前向加速、约 1.7–1.9 倍前后向加速不等于正式训练 step 加速，也不构成正确性通过。

## 分段控制的边界

仅 probe 进程 monkeypatch `Qwen3_5DecoderLayer.forward`：对 batch=1 的 packed linear-attention 层，从显式 text position reset 分段，逐片调用保存的 original forward 再 cat；hidden、position_ids、cos/sin 同步切片。完整 linear decoder（包括 MLP）逐片执行，外层 FSDP hook/checkpoint 保留一次；full-attention 层继续使用原生 varlen packing。无跨 batch 共享可变边界状态，梯度重算可从当前实参复原边界。分段点 GPU→CPU 提取开销包含在时间内。该控制只用于定位，不是已验收的生产修复。

```bash
  --execute --segmented-linear-control \
  --output experiments/sharedexpert_c/logs/packing_probe_repro
```

实际本次使用 `subprocess.Popen(..., start_new_session=True)` 后台运行，PID 1761603；精确命令、非秘密环境和时间见 [launch_01.json](launch_01.json)。源码/config/data/image/token provenance 哈希见 [inputs.json](inputs.json) 与 [report.json](report.json)。原始响应 log-prob 见 `response_log_probs.pt`，真实输入为 `inputs.pt`，完整四 rank 日志为 [run_01.log](run_01.log)，退出和 GPU 释放核对为 [completion_01.json](completion_01.json)。

本测试没有测 8192 长响应、optimizer state、实际 PPO 更新或生产动态 batching 的最坏显存。生产 dynamic batch 按有效 token 近似分组但保留全局 padded 宽度，不能从本地裁剪宽度 1031 的 padded B2 结果推断生产安全。当前结果支持保留已通过 smoke 的 B1/remove_padding 配置；任何新 batching 修复均需先隔离残余梯度差，再做长序列完整训练 smoke。
